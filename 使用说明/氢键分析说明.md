# 氢键时空分析

## 操作

导入多帧轨迹后，进入数据分析，选择氢键时间相关函数、动态氢键数量或一维/二维氢键密度。设置起始帧、结束帧和采样间隔；每个分析组分别多选供体重原子 D、显式氢 H、受体重原子 A。最多12组；名称留空时按原子类型名称生成标签。供体和受体类型允许相同，氢类型不能与重原子类型重合。

确认原始坐标单位。默认 D–A 距离不超过3.5 Å，D–H–A夹角不小于150°；两项均可修改。几何配对时 D–H 截断默认1.2 Å。距离判据以Å输入，软件按原始单位换算。默认优先使用文件中的D–H拓扑；无匹配拓扑时，在截断内匹配最近供体。等距候选不擅自选择。可强制只用拓扑或只用几何配对。视口中自动创建的显示键不作为分析拓扑。

每个唯一D–H–A三元组计为一条氢键。同一D–A之间不同H分别计数；不要将结果与按D–A对合并的定义混用。D–H和D–A向量采用晶胞周期边界的最短连接。周期方向的截断不能超过最小面间距的一半。非周期方向不周期回卷。仅统计分子间氢键时，需勾选对应项，并提供正确、正值的分子编号。

## 时间相关函数

记 H(t) 为采样帧t的氢键三元组集合。对每个起点t0，间歇型为：

`C(k;t0) = |H(t0) ∩ H(t0+k)| / |H(t0)|`

连续型为：

`S(k;t0) = |H(t0) ∩ H(t0+1) ∩ ... ∩ H(t0+k)| / |H(t0)|`

对有足够后续帧且 H(t0) 非空的起点等权平均。间歇型允许中间断裂后重建；连续型要求每一个已采样中间帧存在。未保存或未选取的中间状态无法推断。无有效起点时JSON记录null、TXT为nan，图中留空，不将其记为零。TXT同时导出各组每个滞后下的有效起点数。

TCF依赖稳定的粒子编号；重新排序可按编号匹配。无编号时，仅在确保各帧顺序不变的情况下勾选固定顺序对应。所选粒子的编号或类型变化会停止计算。最大滞后和起点间隔以采样帧为单位。物理时间间隔填写相邻存储帧间隔，软件再乘所选采样步长。当前不进行寿命拟合或自动外推积分。

## 氢键数量及密度

动态数量按帧导出总条数与相对起始帧时间，不是每分子平均配位数。

密度以D–A最短周期连接中点为氢键位置。逐帧计算每个箱内的条数/实际箱体积，再对所选帧等权平均。无氢键帧以零计入平均。一维可选x/y/z；二维可选xy/xz/yz/yx/zx/zy，并可指定法向切片范围。二维输出仍是所选厚度内的体积密度，不是面积密度。重叠分析组独立统计，跨组之和可能重复计算同一条氢键。

笛卡尔模式适用于固定正交晶胞；倾斜或变胞体系可选晶胞分数坐标，x/y/z选项此时对应a/b/c。分数坐标轴为0–1，密度归一化仍使用实际体积。二维多个组使用共同色标。

## 输出与计算设备

点击计算后在独立工作进程中处理，可取消。取消保留上次完整结果，不将未完成计算作为成功结果。输出600 DPI PNG、UTF-8 TXT及计算参数与结果JSON。分析使用原始粒子数据，不受显示半径、隐藏、凝胶替换或当前帧虚拟冰类型影响。

自动模式尝试Dr.Jit CUDA双精度内核，处理距离、角度筛选、等宽直方图、均方位移数值归约和TCF布尔归约。轨迹读取、邻居搜索、编号匹配、周期展开与FFT等仍使用CPU；较大的稀疏TCF也可使用CPU集合计算。没有兼容CUDA GPU或内核运行失败时回退CPU，JSON记录原因。GPU优先不表示全部步骤都在GPU执行，也不保证所有数据规模都加速。

TCF时序超过内存保护阈值时会提示减少帧数、分组或增加采样间隔。应根据采样间隔检查连续TCF是否能描述研究所需的断裂时间尺度。
