# V1.6.8 剪切应变参考帧修复

修复将非零轨迹帧设为剪切应变参考帧时出现 Requested reference frame 0 is out of range 的错误。保留用户选择的参考结构，将用于计算的两个独立快照映射到各自内部第0帧；原始数据、输出中的轨迹帧编号和参考帧编号保持不变。

已用41帧扩展XYZ测试参考帧0、39、40，核验同帧零应变、反向比较、原子编号重排和无编号顺序匹配。剪切应变与已知变形的解析结果一致。晶胞、原子对应关系和足够邻域仍为计算前提。

缺少晶胞与二维模型现在分别提示。普通XYZ可能没有晶胞；固定晶胞可补充同一次模拟的匹配data，变胞轨迹需提供每帧真实晶胞。软件帧编号从0开始，界面39对应文件第40帧；超出帧范围仍会拒绝计算。

退出旧版，在原安装目录运行V1.6.8安装包覆盖升级。原有有效授权继续使用，建议升级前备份显示配置和分析结果。V1.6.6中英文操作手册仍适用，修复内容以本说明为准。
