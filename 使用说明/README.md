## 功能章节

1. 软件概述、安装激活、工作区与视图操作。
2. 分子结构与轨迹导入、拓扑补充、编号匹配、元素识别和统一配色。
3. 原子类型多选、文件半径、统一半径、显示和批量材质。
4. 多组透明水面、不透明凝胶、当前帧冰识别、独立冰类型与冰凝胶。
5. 元素成键、截断编辑、批量删键、裁剪、晶胞和颜色映射。
6. 相机、三光源、明亮显色与厚重阴影、渲染与视口直接出图、DPI和动画。
7. RDF、MSD、一维/二维数密度与质量密度、剪切应力与逐原子剪切应变。
8. 氢键几何判据、动态数量、密度、氢键TCF与普通原子对接触TCF。
9. 图表文字与字体编辑、上标下标、重新出图、数据文件、GPU/CPU和问题排查。
