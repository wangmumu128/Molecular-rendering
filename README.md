## 安装与激活

1. 在 Releases 下载 `MolecularRendering-1.6.1-Windows-x64-Setup.exe`，无需另装 Python。
2. 运行安装程序，可自行选择安装目录，并创建水分子桌面快捷方式。
3. 首次启动显示设备识别码；购买后将订单信息和设备码发给售后邮箱。
4. 收到激活码后粘贴并激活。已有 `.mrlicense` 授权文件也可导入。

安装包目前没有代码签名证书，Windows可能显示未知发布者提示。下载来源和SHA256应与本仓库Release记录一致；无需关闭系统安全防护。

## 功能

- 导入分子结构、晶胞及轨迹，支持 LAMMPS dump/data、XYZ、CIF、PDB、XTD 等格式；具体支持以文件结构和导入结果为准。
- 元素识别、统一原子配色、类型多选、批量半径及显示设置，球体、透明水面、不透明凝胶和当前帧冰组。
- 三光源方向与强度设置、厚重阴影与明亮显色、轨迹播放、PNG/TIF图片及动画导出，也可直接保存视口图片。
- RDF、MSD、一维/二维密度、剪切应力和剪切应变分析。
- 氢键连续/间歇TCF、动态氢键数量、一维/二维氢键密度；供体、氢、受体类型及几何判据可设置。
- 数据分析输出PNG（600 DPI）及TXT；自定义文件名、标题、坐标轴、图例和色标，支持上标、下标。

## 环境与数据

当前安装包仅适用于 Windows 10/11 x64。建议16 GB或以上内存，并预留4 GB安装空间及足够的输出空间；大型轨迹和高分辨率渲染可能需要更多内存。运行速度取决于粒子数量、网格、采样和输出尺寸。

支持的 NVIDIA CUDA 环境优先用于渲染与部分分析数值步骤，不可用时回退CPU。并非所有型号GPU均支持CUDA，轨迹读取、邻居搜索等部分步骤仍在CPU执行。三维视口需要可用的图形驱动。

轨迹与分析在本机处理；激活采用本机验签，应用未设置轨迹或设备码自动上传。设备码由用户主动发给售后。运行设置、授权和日志保存于 `%LOCALAPPDATA%\MR\MolecularRendering\1`，卸载保留该目录，便于重装后恢复。更新前建议备份显示配置和分析结果。
