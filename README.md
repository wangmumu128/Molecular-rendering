## V1.6.5 更新

- 分析图件、图表重新出图、渲染图片、视口截图和动画导出均可选择保存位置；同名自动增加序号。
- 导出目录仅保存图片与TXT/CSV数值数据（动画为MP4）。JSON参数、结果、渲染配置和处理日志单独存放在实际安装目录的`运行记录`文件夹，可从文件菜单打开。

- 新增球体、球棍、棍、细线四种模型样式，支持球体比例和杆径设置，视口、图片与动画一致；保留成键规则和连续水/凝胶表面。

- 对缺少原子类型的轨迹，可选择匹配的拓扑data文件补充；已有类型但缺少元素时，可补充类型名称和配色。

## 安装与激活

1. 在 Releases 下载 `MolecularRendering-1.6.5-Windows-x64-Setup.exe`，无需另装 Python。
2. 运行安装程序，可自行选择安装目录，并创建水分子桌面快捷方式。
3. 首次启动显示设备识别码；购买后将订单信息和设备码发给售后邮箱。
4. 收到激活码后粘贴并激活。已有 `.mrlicense` 授权文件也可导入。

安装包目前没有代码签名证书，Windows可能显示未知发布者提示。下载来源和SHA256应与本仓库Release记录一致；无需关闭系统安全防护。

## 功能

- 导入分子结构、晶胞及轨迹，支持 LAMMPS dump/data、XYZ、CIF、PDB、XTD 等格式；具体支持以文件结构和导入结果为准。
- 元素识别、统一原子配色、拓扑辅助匹配、类型多选、批量半径、材质及显示设置，球体、透明水面、不透明凝胶和当前帧冰组。
- 三光源方向与强度设置、厚重阴影与明亮显色、轨迹播放、PNG/TIF图片及动画导出，也可直接保存视口图片。
- RDF、MSD、一维/二维密度、剪切应力和剪切应变分析。
- 普通原子对距离接触TCF，支持A、B侧多类型选择及连续/间歇两种函数。
- 氢键连续/间歇TCF、动态氢键数量、一维/二维氢键密度；供体、氢、受体类型及几何判据可设置。
- 数据分析输出PNG（600 DPI）及TXT；自定义文件名、标题、坐标轴、图例和色标，支持上标、下标；各类标识可设置字体、字号、粗体和斜体。计算完成后可编辑图表并重新出图，无需重算轨迹。

[普通TCF与图表字体编辑](使用说明/原子对TCF与图表编辑说明.md) · [出图命名与上下标](使用说明/出图命名与上下标说明.md) · [氢键分析说明](使用说明/氢键分析说明.md)

## 环境与数据

当前安装包仅适用于 Windows 10/11 x64。建议16 GB或以上内存，并预留4 GB安装空间及足够的输出空间；大型轨迹和高分辨率渲染可能需要更多内存。运行速度取决于粒子数量、网格、采样和输出尺寸。

支持的 NVIDIA CUDA 环境优先用于渲染与部分分析数值步骤，不可用时回退CPU。并非所有型号GPU均支持CUDA，轨迹读取、邻居搜索等部分步骤仍在CPU执行。三维视口需要可用的图形驱动。

轨迹与分析在本机处理；激活采用本机验签，应用未设置轨迹或设备码自动上传。设备码由用户主动发给售后。设备授权与用户配置仍位于 `%LOCALAPPDATA%\MR\MolecularRendering\1`。新图件由用户选择保存位置；新分析及渲染内部记录位于安装目录的`运行记录`。更新或卸载前请备份结果、显示配置和内部记录；安装程序不主动删除用户生成的记录。
